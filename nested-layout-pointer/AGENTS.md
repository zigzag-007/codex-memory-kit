# Project Agent Instructions

This file exists so Codex finds it automatically at the project root. The real instructions and memory live inside the `.agents` folder, which Codex does not walk into on its own.

Before doing any work in this repository, always read, in this order:

1. `.agents/AGENTS.md` — full workflow rules and how to use local memory.
2. `.agents/agent-memory/AGENTS.md` — project summary and read order for the memory files.
3. Then read whichever file `.agents/agent-memory/AGENTS.md` tells you to read for the current task.

Do not skip this step, even for a small task. These files contain rules that are not repeated here.
